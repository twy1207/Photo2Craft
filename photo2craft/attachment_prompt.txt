PART DIMENSIONS AND POSITION
Each part: id,width,height,depth,attachment,vertical,shell,material,roof,evidence,
inferred. Dimensions are positive fractions <=4 of the BASELINE ROOT dimensions,
not the host dimensions. height=null only for between supports. Use shell=false
for slabs/posts. Existing IDs may be referenced but cannot be reused for additions.
IDs: lowercase letter first, then lowercase letters/digits/_, max40 characters.

attachment={host,face,anchor:[u,v]}. host is an existing volume or added part.
x=right,y=up,z=back; front=min z. Part touches OUTSIDE the host face. For front/back
u,v are CENTER along host x,y; left/right: center along host z,y; top: center along
host x,z. u,v are in [0,1]. For top-face placement v=0 is FRONT edge, v=1 BACK edge.
For a slab whose bottom should match the body's bottom, its center v is half
its height fraction. Keep all added boxes within the existing scene's outer bounds,
including existing roof peaks: no widening/deepening of the frozen envelope.

vertical={mode,lower,upper} overrides vertical placement only:
face: both null, use the attachment's face center (or host top).
on_top: lower=ID,upper=null, bottom meets lower's BOX top.
align_top: lower=null,upper=ID, top matches upper's BOX top.
between: lower=ID,upper=ID,height=null, height derived from lower BOX top to upper
BOX bottom. Use between for supports from a floor to an existing canopy; attach
them to the floor's top and select horizontal positions from the photo. Do not
guess their height independently. Reference graph must be acyclic; footprints of
supports must overlap. No additions may overwrite existing blocks.

Roof={kind:none/flat/gable,rise,ridge_axis:x/z,material}. rise is relative to that
part's box height, 0..2, positive for gable. none=0, flat=0 uses existing top. Use
none for plain posts/slabs. Materials: white_concrete,light_gray_concrete,
gray_concrete,black_concrete,red_concrete,yellow_concrete,bricks,stone_bricks,
sandstone,oak_planks,dark_oak_planks,deepslate_tiles,glass.

unseen completion. Do not add a floor-to-canopy solid box in an open porch. Check
